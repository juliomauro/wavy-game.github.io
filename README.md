# Wavy Pillars

A Game Boy homebrew game about the pillars every Wavy employee should know — built as a fun and memorable way to experience the company culture.

**[▶ Play in the browser](https://wavy-game.github.io)**

---

## About

Wavy Pillars is a homemade Game Boy game (`.gb` ROM) created to bring the values and pillars of Wavy — now part of [Sinch](https://sinch.com) — to life in an unexpected format. Instead of a slide deck, you get a Game Boy cartridge.

The game runs in the browser via a JavaScript Game Boy Color emulator, with full touch controls on mobile and keyboard support on desktop.

---

## Controls

| Action | Keyboard |
|---|---|
| Move | Arrow keys / WASD |
| A | Alt / Z / J |
| B | Ctrl / K / X |
| Start | Enter |
| Select | Shift |

Touch controls are shown automatically on mobile and tablet.
